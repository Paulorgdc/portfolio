# ⚡ PORTFOLIO: Interactive Cyberpunk Terminal & Online Resume

PORTFOLIO is an interactive, web-based digital resume and developer terminal engineered with a high-performance HUD interface, real-time matrix animation effects, and integrated system diagnostics.

## 📌 Project Overview

PORTFOLIO was developed as an interactive web terminal designed to bridge the gap between traditional professional documentation and a modern developer showcase. 

By combining scanline CRT laser animations, dynamic typewriter diagnostics, and modular career blueprints, the platform provides recruiters and engineers with an immersive inspection of core competencies, professional experiences, and open-source ecosystems.

---

## ⚡ Tech Stack

* **Core Engine:** HTML5, Modern CSS3 (Variables, Keyframes & Viewport Grid), Vanilla JavaScript (ES6+)
* **Styling & Effects:** CRT Laser Scanlines, Matrix Flickering Mesh, Dynamic Neon Drop Shadows
* **Typography:** Chakra Petch (Headings & Badges), Share Tech Mono (Terminal Data Stream)
* **Cloud & Hosting:** Vercel Continuous Deployment

---

## 🚀 Key Features

* **HUD System Diagnostics:** Real-time terminal header presenting live operational status, degree progression, and localized data.
* **Dynamic Typewriter Cycle:** Automated telemetry rotating through 8 status phrases with custom blinking cursor optics.
* **Engineered Competency Matrix:** Structural breakdown categorized into Back-end, Front-end, Cloud Infrastructure, and UI/UX.
* **Featured Architecture Showcase:** Direct external routing to core repositories including OreForge, TripWay, and Re-Livro.
* **ATS Compatibility Bridge:** Optimized to complement standard executive CV formats via direct web embedding.
